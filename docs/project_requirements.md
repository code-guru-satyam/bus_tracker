Project Name:
UP Bus Tracker

Goal:
Track government and private buses in real time.

Actors:
1. Passenger
2. Driver
3. Admin

Passenger Features:
- View buses on map
- Search routes
- Estimated arrival time

Driver Features:
- Login
- Start trip
- Share GPS location

Admin Features:
- Add buses
- Add routes
- Monitor fleet

Tech Stack:
Backend: FastAPI
Frontend: React
Database: PostgreSQL
Maps: OpenStreetMap
Realtime: WebSocket
